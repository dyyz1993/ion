# xbrowser suggestion #3 (2026-08-30)

- 主题: console 命令只有 ~5s 采样窗, 无历史缓冲
- 严重度: P3 体验

## 复现
页面加载阶段产生的 console.error / unhandledrejection, 在加载完成后再跑 `xbrowser console` → total: 0

## 建议
1. console 改为累积缓冲 (session 生命周期内所有消息), 加 `--tail N` / `--since`
2. 或文档明示 "仅采样调用窗口", 引导用户用 addinitscript 兜底 (本次实测 addinitscript 方案可行, 但 daemon 重启即丢)

## 附带确认 (做得好)
- CDP-Guard 拦截 eval 内 el.click() 合成事件, 提示清晰 (isTrusted=false), 避免假阳性测试结果
- `find text` 依赖可见文本节点, 对含 emoji/嵌套结构的元素命中率一般, 建议支持子串+最近可点击祖先
