# xbrowser bug #1 (2026-08-30)

- 命令: 任意 `xbrowser --session <s> <cmd>`(daemon 复活时)
- 严重度: P1 功能异常 (长会话中途 daemon 崩溃 → 自启浏览器被关闭 → 页面丢成 about:blank)

## 复现
1. 某进程并发重建 `/Users/xuyingzhou/Project/study-node-ts/xbrowser/dist/` (本轮为另一 agent 在改 xbrowser 源码)
2. 运行中的 daemon 执行下一条命令时:
   `Error [ERR_MODULE_NOT_FOUND]: Cannot find module '.../dist/browser-6LH6KJSW.js' imported from .../dist/cli.js`
   且打印 `process_exit | Session ...: Closing self-launched browser.`

## 预期 vs 实际
- 预期: 模块缺失时给出可读错误 / 不关闭已启动的浏览器 (页面有未保存测试状态)
- 实际: daemon 崩溃 + 浏览器整体关闭; 新 daemon 再起后落到 about:blank, tab 全换, window 上的 JS 状态全丢
- 本轮实测发生 4+ 次, 每次表现为"页面随机变 about:blank", 初看极像被测页面的 bug, 排查成本高

## 源码定位（只读分析，不改代码）
- 文件: `dist/cli.js` 顶部静态 import hash 化 chunk (browser-6LH6KJSW.js)
- 根因/建议方向: 重建 dist 时旧 hash chunk 被删, 运行中的 cli 解析失败。建议: ① rebuild 写入新目录后原子替换(或保留旧 chunk 一个宽限期); ② process_exit 前若非用户主动 close, 打印更显眼警告
