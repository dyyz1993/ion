## Bugs 发现 (详见报告)
1. 发送失败空原因 — gateway /api/send 不透传 data.error, 前端读 r.error (index.html:2751)
2. bootstrap 瞬时失败卡 "开始你的第一个任务" 欢迎页 (仅 2.2s 一次重试); 且欢迎块在新消息到来后不消失
3. 切换会话 syscard "已切换到会话" 可能被 bootstrap refetch 竞态清掉 (T5 路径实测缺失, T8 路径正常)
4. 模型下拉首次加载失败无自动重试 ("加载失败" 挂住, 手动刷新才恢复)
5. 桌面开右侧 info 面板 → 缩到 375 → 右面板残留覆盖聊天区 (错行/裁切)
6. host 重启窗口期发送失败+自动恢复后仍失败一次; 直连 RPC 已恢复时 UI 未提示可重试

## 环境事故 (非 WebUI bug)
- xbrowser daemon 在 dist 被并发重建时 ERR_MODULE_NOT_FOUND 崩溃 → 自启浏览器被关闭 → 页面变 about:blank ×4 次
- xbrowser chain 解析: eval 内分号被剥离; -e 传 "click sel" 整串进 eval
- CDP-Guard 拦 eval 内 el.click() (合理), 用 mouse click 坐标替代

## ⚠️ 压测方法论坑 (新发现, 后续复用必读)
- **注入 DOM 会被 bootstrap 清场**: 页面 bootstrap 内 3s/2.2s 延迟重拉(index.html:1892/1927)检查 `.tc-empty-state` 是否存在 — bug#2(欢迎块不消失)使它永远命中 → 全量重渲染 → 注入的 DOM 被清。实测: 注入(601 children)后 12s 内被清回欢迎块。
- **对策**: 测量 eval 开头 `window.__bootstrapOrig=window.bootstrap; window.bootstrap=()=>Promise.resolve('stubbed')`(页面内 global binding 替换, 不改产品代码), 注入+滚动+采集合并进单个 async eval, 结尾还原 + goto 刷新恢复纯净堆。**长任务观察器 `window.__lt` 跨 eval 存活**(PerformanceObserver 挂 window 不受清场影响)。
