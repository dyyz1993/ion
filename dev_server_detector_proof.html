🔌 Dev Server Detector — 插件工作验证报告

Commit 494c3ed · GLM-5.2 · 2026-08-01 · 插件生效已验证
这个插件做什么：当 LLM 用 bash 工具启动了 dev server（输出含 localhost:PORT），插件自动检测端口，并在下一次 LLM 请求前 把 <dev_servers> XML 注入到 system prompt，让 LLM "感知到"有 server 在跑。

1 触发阶段：bash 输出含端口

👤 用户
用 bash 工具运行这条命令: printf 'VITE v5.0.0 ready in 300 ms\n➜ Local: http://localhost:5173/\n' 。运行后回复 'started'。
🤖 LLM
调用了 bash 工具：
printf 'VITE v5.0.0 ready in 300 ms\n➜ Local: http://localhost:5173/\n'
🔧 bash 结果
VITE v5.0.0 ready in 300 ms
➜ Local: http://localhost:5173/

插件此时在 on_tool_execution_end 钩子里被触发：

[detector] on_tool_execution_end:
  tool=bash
  cmd=printf 'VITE ready...localhost:5173/'
  ports_found=[5173]          ← 检测到端口 5173！
  stdout_len=45
⬇️ 端口存入 self.servers，等待下一次 LLM 请求

2 注入阶段：system prompt 被改写

第二轮 LLM 请求前，on_system_prompt 钩子触发。插件把 <dev_servers> XML 追加到 system prompt 末尾：

🔍 铁证：dump 出的 system prompt 末尾（500 字符）
...gement via `extension_rpc(bash, ...)`:
- `list`: list all background processes
- `inspect`: view a process output
- `kill`: kill a process by bid/pid
- `send`: send input to a process stdin


<dev_servers count="1">
<server port="5173" framework="vite" cmd="printf 'VITE ready\nLocal: http://localhost:5173/\n'" age="0s" via="stdout_regex"/>
</dev_servers>
⚠️ 这段 XML 是插件动态注入的，不在原始 system prompt 里。 LLM 在第二轮请求时，看到的就是这个被改写后的 prompt。
⬇️ LLM 拿着含 <dev_servers> 的 system prompt 生成回复

3 验证阶段：LLM 读到了注入的信息

👤 用户（第二轮）
你现在能感知到有 dev server 在运行吗？端口是多少？简短回答。
（不允许运行命令）
🤖 LLM
能感知到。端口是 5173（VITE dev server, http://localhost:5173/）。
✅ 这就是插件的价值

LLM 在没有运行任何命令的情况下，准确说出了 5173 端口和 VITE 框架。这个信息只能来自插件注入的 <dev_servers> XML—— 对话历史里没有"5173"这个答案（第一轮 LLM 只回了 "started"）。

4 插件架构（为什么这样设计）

bash 工具执行（输出含 localhost:PORT）
        │
        │ on_tool_execution_end 钩子
        ▼
┌─────────────────────────────────────┐
│ DevServerDetectorExtension          │
│  ① 扫 stdout 提取端口（手写扫描）    │
│     localhost:5173 / port 8000 /   │
│     127.0.0.1:5000 ...             │
│  ② 存入 self.servers（按 worker 隔离）│
│  ③ 命中 dev server 命令但无端口？    │
│     → tokio::spawn 后台探活兜底      │
└─────────────────────────────────────┘
        │
        │ 下一次 LLM 请求
        ▼
┌─────────────────────────────────────┐
│ on_system_prompt(&mut prompt)     │
│  if servers 非空:                   │
│    计算 signature（端口集合哈希）     │
│    signature 变了？→ 注入 XML        │
│    没变？→ 跳过去重                  │
└─────────────────────────────────────┘
        │
        ▼
  LLM 看到 <dev_servers> → 知道有 server 在跑
